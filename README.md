# 🍺 Springfield Heroes: Nuclear Warrior Edition

Vitajte v projekte mojej RPG hry! Je to mix mechaník **Shakes & Fidget** s vizuálnym štýlom žltých postavičiek a možnosťami úprav postavy ako v **The Sims 4**.

## 👤 Aktuálny Avatar: "Atómový Dračí Barbar"

Tento hrdina bol vytvorený v našom editore postáv. Tu sú jeho špecifikácie:

| Kategória | Komponent | Popis |
| :--- | :--- | :--- |
| **Hlava** | `1B` | Žltá tvár, nahnevaný výraz, ryšavá brada. |
| **Vlasy** | `2B` | Modré trsy vlasov po bokoch (Krusty style). |
| **Prilba** | **Dračia** | Masívna kovová dračia prilba so svietiacimi červenými očami. |
| **Zbraň** | **Atómová** | Žiariaca rádioaktívna tyč (Atomic Rod). |
| **Brnenie** | **Dračie** | Šrotové brnenie pripomínajúce dračie šupiny. |
